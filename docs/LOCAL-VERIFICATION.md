# 验证范围

版本 1.5.0，2026-09-29。

- 后端自动测试覆盖控制、设备扫描、API、认证、安装器逻辑与演示隔离。
- 前端逻辑测试覆盖控制队列、演示状态持久化、温控、OLED、场景和设备切换。
- Linux ARM64 Docker 已验证启动、健康检查、API、数据保留及无硬件时的认证行为。
- 静态演示已验证根域名与子目录访问；无真实设备控制请求，API 文档只读。
- 真实服务与演示设备往返切换已验证；演示操作不会改变真实硬件配置。
- 桌面及 390 × 844 移动视口已检查。

AMD64 尚未完成实机运行验证。新树莓派的完整首次安装流程仍需更多硬件环境验证；目前已测试安装器逻辑和现有设备控制。

浏览器与 Pillow 的文字栅格化可能存在细微差异。演示内的 OLED 画布与三维屏幕共用同一份位图。灯光预览用于表达效果和节奏，不能复现肉眼曝光或原厂固件的精确相位。
